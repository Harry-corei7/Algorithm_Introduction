## 题目内容

意图分类是一种常见的 $NLP$ 任务，现在需要实现一个基于逻辑回归的意图分类系统(二分类)。本系统的输入是一个已处理的特征序列，输出是意图标签 (0 或 1)。请根据以下步骤实现该分类器：

1、数据预处理：对输入(特征序列，即仅包含大写字母 $ABCDEFG$ 的序列)进行 $one-hot$ 编码，编码时的特征顺序是 $ABCDEFG$；某个特征存在取 1，不存在取 0；

2、模型初始化：构造一个单层的训练网络，初始化权重 $w$ 和偏置 $b$ 初始化的值全部设为 0；

3、模型训练：使用 $Sigmoid$ 函数计算预测值，使用交叉熵损失函数训练，使用梯度下降算法更新参数；训练过程中使用训练数据进行训练，相关超参数为：学习率 0.1，训练轮数 20，$batch$ 大小为 1；
   (1) $Sigmoid$ 函数公式:
   
   $$ \sigma(z) = \frac{1}{1+e^{-z}} \text{，其中 } z = w \cdot x + b \text{(} x \text{为输入特征向量)。} $$

4.模型预测：对测试数据进行预测，首先使用 $sigmoid$ 函数计算预测值，然后做二值化处理(大于 0.5 认为是类别 1，否则是类别 0)

## 输入描述

第一行输入 $N$ 和 $M$，$N(10 <= N <= 100)$ 表示训练数据条数，$M(2 <= M <= 10)$ 表示测试数据条数；

接下来 $N$ 行是训练数据，每行包含两部分内容(空格隔开)
  - 即代表输入的特征序列(由大写字母 $ABCDEFG$ 构成的字符串，长度范围是 $[3, 7]$ )和该条数据的意图标签(使用数字 0 或 1 表示)；

在接下来 $M$ 行是测试数据的特征序列。

## 输出描述

输出有 $M$ 行，每行是测试输出，即用数字 0 或 1 表示的意图标签。

`python解法(非Torch)`
```python
import sys
import math

def solve():
    data = sys.stdin.read().split()
    it = iter(data)
    N = int(next(it))
    M = int(next(it))

    
    # ---算法---
    # 特征映射表 (A-G 对应索引 0-6)
    feature_map = {'A': 0, 'B': 1, 'C': 2, 'D': 3, 'E': 4, 'F': 5, 'G': 6}
    num_features = 7

    train_X = []
    train_Y = []
    test_X = []

    # 读取测试数据
    for _ in range(N):
        seq = str(next(it))
        label = int(next(it))

        # 初始化全0向量
        one_hot_vec = [0.0] * len(feature_map)
        # 对向量进行赋值
        for char in seq:
            if(char in feature_map):
                one_hot_vec[feature_map[char]] = 1
        
        train_X.append(one_hot_vec)
        train_Y.append(label)
    
    # 读取测试数据
    for _ in range(M):
        seq = str(next(it))

        # 初始化全0向量
        one_hot_vec = [0.0] * len(feature_map)
        # 对向量进行赋值
        for char in seq:
            if(char in feature_map):
                one_hot_vec[feature_map[char]] = 1
        
        test_X.append(one_hot_vec)
    
    # 模型初始化
    # 权重 w 和 偏置 b 初始化为 0
    w = [0.0] * len(feature_map)
    b = 0.0
    # 超参数
    lr = 0.1
    epochs = 20

    # 定义 Sigmoid 函数
    def Sigmoid(z):
        if(z >= 0):
            return 1.0 / (1.0 + math.exp(-z))
        else:
            return math.exp(z) / (1.0 + math.exp(z)) # 公式变形，防止数值过大导致溢出

    # 训练
    for epoch in range(epochs):
        for i in range(N):
            z = b

            for j in range(num_features):
                z += w[j] * train_X[i][j] # z = w * x + b
            z = Sigmoid(z)
            error =  z - train_Y[i] # 计算误差：注意顺序，必须是z - Y

            # 更新参数(梯度下降)
            for j in range(num_features):
                w[j] = w[j] - lr * error * train_X[i][j]
            b = b - lr * error
    
    # 模型预测与输出
    for i in range(M):
        z = b
        for j in range(num_features):
            z += w[j] * test_X[i][j]
        z = Sigmoid(z)
        if(z > 0.5): print("1")
        else: print("0")

if __name__ == "__main__":
    solve()
```
